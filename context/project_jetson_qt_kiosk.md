**KEY FINDING — Qt eglfs is BROKEN here.** Stock Ubuntu Qt5 (5.15.3) `eglfs` SEGFAULTS on this L4T/Tegra GBM stack: `eglfs_kms` (GBM) gets all the way to "Creating gbm_surface for screen DP1" → "Could not create surface with EGL_NATIVE_VISUAL_ID, falling back to format 34325258 (XR24)" → segfault; `eglfs_kms_egldevice` → "Could not open DRM (NV) device" → segfault. `QSG_RENDER_LOOP=basic`, hidecursor, both integrations — all still crash. nvidia GBM backends ARE present (`/usr/lib/aarch64-linux-gnu/gbm/nvidia-drm_gbm.so` → libnvidia-allocator) and nvidia EGL (`tegra-egl/libEGL_nvidia`). The stock Qt just isn't patched for Tegra GBM. **Do NOT waste time on eglfs — use Weston.**

**WORKING STACK = Weston (Wayland) + Qt Wayland client.** Weston (`/usr/bin/weston`, already installed) drives DP-1 fine over SSH (gets DRM master via logind, even from an SSH session). Run:
```
export XDG_RUNTIME_DIR=/run/user/1000
setsid weston --backend=drm-backend.so --socket=wayland-av --idle-time=0 >/tmp/w.log 2>&1 </dev/null &
# then the Qt app as a client:
setsid env XDG_RUNTIME_DIR=/run/user/1000 WAYLAND_DISPLAY=wayland-av QT_QPA_PLATFORM=wayland ./avatarapp >/tmp/app.log 2>&1 </dev/null &
```
App connects, shows fullscreen, only harmless warning "Wayland does not support QWindow::requestActivate()". `weston-screenshooter` is NOT installed (can't screenshot remotely — confirm visually).
