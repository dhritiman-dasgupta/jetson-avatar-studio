**WHY NeuTTS (vs F5/OpenVoice/XTTS/etc):** light zero-shot cloner (~0.5GB Q4 GGUF backbone + NeuCodec), 3s clone, llama.cpp-based (no growl). Research ranked it #1 for low-mem zero-shot clone on 8GB Orin.

**INSTALL (isolated venv `~/neutts-venv`, easy cleanup):** `python3 -m venv ~/neutts-venv`; apt `espeak-ng`. **Package is `neuttsair` — NOT on PyPI**, install `pip install --no-deps git+https://github.com/neuphonic/neutts-air.git` (real impl in `neutts.neutts`; `neuttsair.neutts.NeuTTSAir` is a thin subclass). Deps: `neucodec llama-cpp-python soundfile phonemizer librosa transformers resemble-perth`. **EXACT versions matter (neutts 1.2.0 pins):** `transformers==4.56.1` (5.x breaks HubertModel import), `soundfile` (0.13/0.14 ok), `resemble-perth==1.0.1` (watermarker, required at infer). HF models auto-download ~3.8GB to `~/.cache/huggingface` (`neuphonic/neutts-air-q4-gguf` backbone + `neuphonic/neucodec`).

**GPU CONFIG (KEY):** NeuTTS GGUF backbone → `backbone_device="gpu"` sets llama-cpp `n_gpu_layers=-1`+flash_attn, BUT needs **llama-cpp-python REBUILT with CUDA**: `CUDACXX=/usr/local/cuda/bin/nvcc CMAKE_ARGS='-DGGML_CUDA=on -DCMAKE_CUDA_ARCHITECTURES=87' FORCE_CMAKE=1 pip install llama-cpp-python --no-cache-dir --force-reinstall --no-binary llama-cpp-python` (~20min build, CUDA 12.6 toolkit present). Codec `codec_device="cuda"` needs **CUDA torch** (CPU torch from pytorch index won't do GPU): install `torch==2.8.0 torchaudio==2.8.0 --index-url https://pypi.jetson-ai-lab.io/jp6/cu126` (jetson-ai-lab has torch 2.8/2.9/2.10/2.11 cu126; **MUST match torchaudio version exactly or `undefined symbol: aoti_torch_create_device_guard`**). **numpy: jetson torch wants <2, neucodec/neutts declare >=2 — but numpy 1.26.4 WORKS fine in practice (pip warns, runtime OK).**

**PERF (warm, persistent worker — what matters):** full-GPU (backbone+codec CUDA) **warm RTF ~1.36** (2.5s audio in 3.5s). Cold/first-call is misleading: ~80s model load + ~12s first-synth CUDA-kernel warm-up are ONE-TIME at startup (per-process, mirror with a warm-up synth like f5_worker). Backbone-GPU+codec-CPU ~RTF 1.7. CPU-only ~3.7. The codec ONNX decoder (`neucodec-onnx-decoder`) is **CPU-only** per neutts code (can't GPU it). GPU is mostly idle during synth except a brief backbone spike → cost is dominated by codec; codec-on-CUDA wins warm.

So NeuTTS must REPLACE F5, not coexist. Standalone (orchestrator stopped) NeuTTS-GPU is stable.
